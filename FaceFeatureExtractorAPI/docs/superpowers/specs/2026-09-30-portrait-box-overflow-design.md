# TASK-2026-001 白底归档轻微检测框越界修正

2026-09-30。用户提供考勤特写，已确认“轻微框越界使用图内有效区域、关键点和抠图通过才出图、仅改白底归档、接口不变”，并回复“实施”，授权修复、原图回归及上线。本补充设计修正前版把所有 raw box 越界等同真实裁切的规则。

## 证据与方案

717×720 输入在线 API 2.3.0 返回 FACE_CROPPED（算法约38ms）。相同本地模型检测到单脸，原框 (58.4503,31.3758,610.5590,737.0614)，下边界超过图像17.0614像素；选择/五点几何成功、五点均在图内。pipeline.py 原始框必须完全在图内的判断先于对齐/抠图拒绝，不能据此证明五官已缺失。

选定：只在 analyze_portrait_quality（face_archive使用）中对轻微模型框外扩作有限容错，后续使用已裁至图内的框计算可见分辨率、质量和构图；添加既有 PORTRAIT_SOURCE_LIMITED 提醒。raw box 保留供边界判断，不修改检测器输出或全局 selector。

未选：去掉所有越界检查会放行严重缺失；让客户端补边/换接口会转移算法责任且改变调用方式。本轮不实施这两种方案。

## 明确边界

- 对每侧外扩取非负溢出量，水平除以原框宽、垂直除以原框高，各侧不得超过0.05（包含边界）。裁至图内面积/原框面积至少0.90（包含边界）。常量固定在 portrait 专用纯函数模块，非请求参数、不是模型精度标定结果。
- 原框有限、正宽高；可见框正面积；目标选择成功、五点形状/有限/几何通过且全部位于源图实际像素范围；裁后宽高仍至少 portrait profile 的112×112。像素索引边界沿用x<width/y<height，框右/下边界允许等于width/height。
- 无脸、歧义目标、越界超过预算、关键点越界/无效、裁后尺寸不足、推理失败与坏蒙版仍失败，无派生图；禁止统一把 FACE_CROPPED 当软码。
- analyze_quality/analyze_trusted、head_shoulders、images/quick/full/presence/witness严格行为保持不变；portrait仍不提取embedding。
- 使用真实源像素，不生成缺失部位；alpha覆盖和质量门槛不改。成功有图为REVIEW并含SOURCE_LIMITED，允许合并原质量/构图提醒。
